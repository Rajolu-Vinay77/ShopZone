# ShopZone

A basic Amazon-style shopping website built with plain HTML, CSS and JavaScript.

## Features
- Product grid with ratings and prices
- Search, category filter and sorting
- Shopping cart (add, change quantity, remove) saved in localStorage
- Demo checkout

## Run locally
Open `index.html` in a browser, or run `npm start`.

## Open in a sandbox
Replace `github.com` with `githubbox.com` in this repo's URL:

`https://githubbox.com/<your-username>/<repo-name>`

This opens the repo in CodeSandbox with a live preview.
